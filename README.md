# 🔍 Пять поросят

Детективная текстовая игра по мотивам романа Агаты Кристи «Пять поросят».  
Вы — Эркюль Пуаро, который заново расследует убийство художника Эмиаса Крейла спустя 16 лет. Допрашивайте подозреваемых, собирайте улики и найдите настоящего убийцу.

Игра работает в браузере (Flask + HTML/JS), ответы подозреваемых генерируются нейросетью **Llama 4 Scout** через [Groq API](https://groq.com/).

---

## Сюжет

Англия, 1938 год. Шестнадцать лет назад был отравлен Эмиас Крейл. Его жену осудили, она умерла в тюрьме. Теперь её дочь просит вас доказать невиновность матери.  
Пять подозреваемых, пять историй, пять версий правды. Вам предстоит раскрыть тайну, которая долгие годы скрывалась даже от самого Пуаро.

---

## Механика

- **Допрос** – каждому подозреваемому можно задавать вопросы в свободной форме.
- **Нейросеть** – персонаж отвечает в своём характере, может врать, уклоняться или нервничать. Следит за контекстом.
- **Улики** – выделяйте мышкой фрагменты ответов, чтобы сохранить их в блокнот.
- **Вынесение приговора** – допросив всех, ответьте на вопросы викторины и укажите убийцу.
- **Реиграбельность** – каждый диалог уникален.

## Установка

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/ваш-username/пять-поросят.git
cd TS2026
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Задайте ключ Groq API
Создайте файл `core/config.py` с вашим ключом:
```python
GROQ_API_KEY = "gsk_..."
```

### 4. Запустите сервер
```bash
python Response/WorkWithHTML.py
```

### 5. Откройте в браузере
Перейдите по адресу [http://127.0.0.1:5000](http://127.0.0.1:5000)

##  Настройка персонажей

Каждый персонаж имеет файл `Docs/<Name> - PRESS.txt` с дополнительной информацией о характере, мотивах и секретах.  
Пример содержимого для `Elsa - PRESS.txt`:

```
Ты была любовницей Эмиаса. Ты до сих пор его любишь и не веришь, что могла стать причиной его гибели.
Твоя соперница – Кэролайн. Ты ненавидела её, но прямых доказательств твоей вины нет.
```

Эти файлы можно редактировать, влияя на отыгрыш модели.

##  УправлениеБыстрый старт

- **Начало**: пройдите вступительные экраны.
- **Допрос**: кликните на портрет подозреваемого → введите вопрос в поле ввода → Enter.
- **Улика**: выделите мышью фразу в ответе, она сохранится в блокнот.
- **Блокнот улик**: кнопка 🔍 в правом верхнем углу главного экрана.
- **Приговор**: кнопка ⚖️ внизу экрана (становится активной после допроса всех пятерых).

Во время допроса персонаж устаёт (шкала `angry`). Если она достигнет 100%, допрос прервётся.

##  Развёртывание на сервере

Для публичного доступа можно использовать [Render](https://render.com/) (бесплатный план):

1. Загрузите проект на GitHub.
2. Создайте новый Web Service на Render, подключив репозиторий.
3. Build Command: `pip install -r requirements.txt`  
   Start Command: `python Response/WorkWithHTML.py`
4. В переменных окружения укажите `GROQ_API_KEY`.
5. После деплоя замените `fetch('/ask', ...)` в `template.html` на полный URL вашего сервера.
